# 品牌物料：服务器端可配公司品牌，客户端接入后自动换牌

> 状态：已实现（设计定稿 2026-10-08；服务端批＋客户端接入批＋设置页批
> 落地，实现差异已回填 §2/§4/§6——缓存路径、信号驱动形态、clear 路由、
> fetch 时点四处与原稿不同，以回填后为准）。目标：管理端配置公司名/
> logo/主题色/登录页文案/启动页（可选）→ 客户端登录后自动拉取应用（界面
> 标题/登录窗/侧栏/窗口图标随换，本地缓存+版本号，变更热生效，离线用缓存）；
> 未配置＝memex 自己的标兜底，行为不变。

## 0. 范围拍板

- **存储**：服务端库单行聚合表 `branding`（id=1），不走通用 kv——品牌是
  一个聚合体（一次读全量、version 单调递增判变更）。
- **读面免鉴权**：品牌物料非敏感（公司名/logo/文案），登录窗要在鉴权前
  显示——GET 三路由全部免鉴权；客户端拉取不依赖文件面登录（QNetwork-
  AccessManager 直拉，离线/文件面未启用＝静默用缓存或默认标）。
- **写面判权**：az 新规则 `branding-manage`（ExplicitAllow＝effective_roles
  含 org-admin；未命中 default-deny）。管理写走 FilesClient 鉴权会话
  （客户端品牌设置页），运维兜底走 CLI（store 直写）。
- **主题色选型**：品牌 accent 是**局部品牌色**（侧栏品牌行/登录窗 logo 底/
  登录按钮），**不进 R19 主题令牌系统**——ThemeTokens.brand 是用户主题
  选择的一部分，服务器品牌不应覆盖用户的亮暗主题偏好；两套色各管各的面。
- **头像占位现状如实注明**：客户端当前无独立头像组件（气泡/列表不以头像
  展示）——品牌头像占位色落在侧栏品牌行 logo 底与登录窗 logo 底；将来
  出头像组件时从 BrandKit.accent() 取色即可。

## 1. 存储（store 单行聚合表）

```sql
CREATE TABLE IF NOT EXISTS branding (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  company_name TEXT NOT NULL DEFAULT '',
  accent       TEXT NOT NULL DEFAULT '',   -- '#rrggbb'，空=未配
  slogan       TEXT NOT NULL DEFAULT '',   -- 登录页文案，空=未配
  logo         BLOB,                       -- PNG 字节，NULL=未配
  splash       BLOB,                       -- PNG 字节，NULL=未配（可选件）
  version      INTEGER NOT NULL DEFAULT 0, -- 每次写 +1（变更判据）
  updated_ms   INTEGER NOT NULL DEFAULT 0
);
```

方法：`branding_get()`（无行返回默认全空 version 0）、`branding_set(name,
accent, slogan, ts_ms)`（文本三件，version+1）、`branding_set_logo(bytes,
ts_ms)` / `branding_set_splash(bytes, ts_ms)`、`branding_clear_logo()` /
`branding_clear_splash()`（每次写 version+1；PNG 校验在路由层，store 只
存字节）。

## 2. 路由（FileServer 六条：读三免鉴权＋写三判权；实现回填）

- `GET /files/branding`（**免鉴权**）：`{company_name, accent, slogan,
  version, has_logo, has_splash}`——不含字节，客户端比对 version 决定
  是否再拉 PNG。
- `GET /files/branding/logo` / `GET /files/branding/splash`（**免鉴权**）：
  `image/png` 字节；未配 404（客户端回落默认标）。
- `POST /files/branding`（`branding-manage`）：JSON `{company_name?, accent?,
  slogan?, clear_logo?, clear_splash?}`——文本字段缺省=不动，显式空串=
  清空；accent 形态门 `#rrggbb`（坏形态 400）；clear_* 布尔（非布尔
  400）＝素材清除，清除即一次独立动作 version+1（原稿「HTTP 面无 clear
  路由、清空走 CLI」已被本字段取代——品牌设置页「清除」按钮所需）。
  空对象（无可写 branded 字段）400。写后回带新 version。
- 路由感知 body_cap：品牌素材路由放行 512KiB+64KiB 余量（读全 body 才能
  回语义化 413 文案；带外荒谬大包仍撞 64KiB 通用 cap 层）。
- `POST /files/branding/logo` / `POST /files/branding/splash`（同判权）：
  body＝PNG 原始字节。校验：**PNG magic**（8 字节 `89 50 4E 47 0D 0A 1A
  0A`）不过 415；**大小 ≤512KiB** 超 413；**IHDR 尺寸 ≤2048×2048**（偏移
  16..24 宽高各 4 字节大端）超 413（文案区分「尺寸超限」）。合法＝落库
  version+1，回 `{ok, version}`。

## 3. CLI（运维兜底，store 直写不经 HTTP）

```
memex_server branding show   --db PATH
memex_server branding set    --db PATH [--company NAME] [--accent '#rrggbb']
                             [--slogan TEXT] [--logo FILE.png] [--splash FILE.png]
                             [--clear-logo] [--clear-splash]
```

set 只动给出的项（缺省项不动）；logo/splash 传文件路径（同路由层 PNG
校验，CLI 侧校验失败非零退出并明示原因）。

## 4. 客户端（BrandKit ＋ 品牌设置页）

**BrandKit**（client/app/brand_kit.{hpp,cpp}，应用级单例）：

- 状态：`company_name / accent(QColor，无效=未配) / slogan / logo(QPixmap)
  / splash(QPixmap) / version`，初始全空＝memex 默认标。
- 拉取：`fetch(host, files_port)`——NAM GET `/files/branding`（免鉴权），
  version 与本地不同（或本地无 logo 而 has_logo）再 GET PNG；成功即
  `apply_all()` ＋ 落缓存。失败静默（文件面未启用/离线＝保持现状）。
- 缓存（实现回填）：本 Qt 版本无 `AppCacheLocation` 枚举——落
  `QStandardPaths::AppDataLocation/brand/` 下 `brand.json` + `logo.png` +
  `splash.png`（`MEMEX_TEST_BRAND_DIR` 环境变量测试覆写缝隙，照 emoji
  缓存先例）；启动时 `load_cache()` 先行（离线也有牌），fetch 成功后
  覆盖（变更热生效）。
- 应用面（实现回填）：未走 `apply_window/apply_login_dialog` 显式调用
  形态，改为 **brand_applied 信号驱动**——主窗构造尾 connect 该信号到
  `apply_brand()`（windowTitle＝公司名否则 "Memex"、windowIcon 与托盘
  ＝logo 非空 QIcon 否则 qrc 多尺寸默认标＋程序绘制回落、侧栏品牌行
  显隐——无牌隐藏＝没配就不变）；登录窗为重写实现（顶部品牌区 logo
  40×40＋公司名 bold＋slogan，无牌不显示；标题随公司名）。
- 接线（实现回填）：fetch 时点早于原稿——登录窗 accept 后**立即**
  `fetch(host, files_port)`（GET 免鉴权＝鉴权前可用，不待 logged_in；
  差异：凭据错时品牌仍能拉到，属免鉴权口径的自然结果）。文件口取
  QSettings `collab/files_port`（登录窗加「文件口」行，缺省 24362，与
  协作口分列）；BrandKit 拉取失败不影响登录流程（静默保持现状）。

**品牌设置页**（client/app/brand_settings_page.{hpp,cpp}，独立 QDialog 同
构既有 dialog 套路）：连接区（host/文件口/账号/口令）→ FilesClient 登录；
展示区（当前公司名/accent/slogan/是否有 logo/splash/版本，连接后回显）；
编辑区：公司名行（留空=清空）/ accent（hex 输入＋QColorDialog 取色，
坏形态本地拒不发网）/ 登录页文案行 / logo 文件选择（QFileDialog＋
QLabel 即时预览，QPixmap 打不开即本地拒）/ splash 同（可选）＋「清除
logo」「清除 splash」；「保存文本」＝POST /files/branding、「上传素材」
＝（选了文件再）POST logo/splash。403 状态行明示「品牌设置归 org-admin」
（统一失败通道透传服务端语义化 413/415 文案）。主窗「设置」菜单加
「品牌物料…」（QPointer 懒建 WA_DeleteOnClose；原稿写「选项」菜单，
实际菜单名＝「设置」，落实现为准）。保存/清除/上传成功后触发 BrandKit
本机 fetch（设置即时生效＝本机先见）。

## 5. 素材规范（上传校验与设计建议）

| 项 | 格式 | 建议尺寸 | 上限 | 说明 |
|---|---|---|---|---|
| logo | PNG（透明底） | 512×512 正方形 | 512KiB、≤2048² | 窗口图标/托盘/侧栏/登录窗共用，客户端按位自动缩放（QIcon 多尺寸插值）；非正方形可用但圆角裁切以短边计 |
| splash | PNG | 1024×768 以内 | 512KiB、≤2048² | 可选件；启动页/登录窗横幅，客户端等比缩放 |
| accent | `#rrggbb` | — | — | 建议与 logo 主色一致；深浅主题下由 brand_text 提亮/压暗规则另算（现局部应用不自动变换，选色时自验对比度） |
| company_name | 文本 | ≤32 字 | — | 窗口标题/侧栏/登录窗 |
| slogan | 文本 | ≤64 字 | — | 登录页文案行 |

## 6. 测试口径

- server `test_files_api` 扩「品牌物料」段：免鉴权 GET 默认全空 version 0
  ／POST 未登录 401、非 org-admin 403、org-admin 200 且 version+1／accent
  坏形态 400／logo 非 PNG 415、超 512KiB 413、合法 200 后免鉴权 GET logo

## 7. 不做（如实注明）

- 不做多品牌租户（单行表＝全服务器一套牌）。
- 品牌变更不主动推送在线客户端（拉取＋version 比对；在线客户端下次
  登录/设置页打开时热生效——「变更热生效」以拉取时点为准）。
- 不做启动全屏 splash 展示（splash 素材现用于登录窗横幅；全屏启动页
  属桌面集成另批）。
- 头像占位面（§0）与全局主题令牌替换（§0 选型）不在本件。
