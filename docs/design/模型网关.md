# 模型网关设计稿（平台三期）

OpenAI 兼容入口：内网服务（群内智能助手等 bot）以 Chat Completions 形态
调用模型，网关负责端点登记、路由、降级、调用审计。**归档数据仅本地模型
——规则写死在代码，不做成配置。**

## 0. 范围

**本笔落地**：端点登记（CLI）、路由与降级、调用审计、归档红线、
OpenAI 兼容 `/v1/chat/completions`、Bearer=bot token。

**留后续（如实注明）**：流式（SSE）回包；多模态；配额/限流；端点健康
探测；管理 UI（CLI 已覆盖）；https 上游（内网口径仅 http）。

## 1. 进程与线程模型

独立端口（`--model-port`，默认关闭）＋独立 io_context＋独立线程：上游
LLM 调用为秒级阻塞，不与 CollabServer/WebhookServer 抢共享 io_context。
自有 ServerStore **第二连接**开同一库文件（`sqlite3_busy_timeout(5s)`
兜写锁竞争）。

## 2. 鉴权

`Authorization: Bearer <bot token>`——主体即 bot（`bot:<name>`）；
disabled 403 同 bot 面口径。群内智能助手等内部服务=bot，与收发面同
一身份体系。

## 3. 请求与路由

```
POST /v1/chat/completions
{"model": "<端点名·可选>", "messages": [...],
 "memex_archive_scope": true·可选}
```

- 候选端点：`enabled=1`，按**注册序**（id 序）即优先序；
- **归档红线**：`memex_archive_scope:true` 的请求只路由 `is_local=1`
  端点；无可用本地端点即 503 拒绝——**请求不出门**（写死在
  model_gateway.cpp，不开放配置；这条腿的假上游零命中有测试钉住）；
- 显式 `model` 命中端点名者提到候选最前（仍在候选集内）；
- 发送体只含 `model`＋`messages`（端点配了 `model` 字段则改写）。

## 4. 降级与转发

| 上游结果 | 行为 |
| --- | --- |
| 2xx | 透传回包（注入 `memex_endpoint` 字段便于排障） |
| 4xx（非 408/429） | 客户端错不降级，原样转发状态与错误体 |
| 408/429/5xx/连接失败/超时 | 降级到下一候选；耗尽即 502 |

上游调用：阻塞式 HTTP/1.1 POST `{base_url}/chat/completions`，读至
EOF（Connection: close）；30s 死线（独立 io_context＋steady_timer，
超时关 socket）。仅支持 `http://`（内网口径）。

## 5. 调用审计

model_calls 表：**一次上游尝试一行**（降级即多行，可对账）——caller、
endpoint、model、archive_scope、prompt_chars/completion_chars（长度
不落正文）、status（0=连接失败/超时）、latency_ms、created_ms。
`memex_server model calls [N]` 台账。

## 6. CLI

```
memex_server model endpoint add <name> --url <http://host[:port][/prefix]>
    [--key <api_key>] [--model <上游模型名>] [--local] --by <账号>
memex_server model endpoint list | remove <name> | enable|disable <name>
memex_server model endpoint local <name> on|off
memex_server model calls [N]
```

## 7. 测试口径

test_model_gateway.cpp：假上游=测试内阻塞 acceptor 线程（恰收 N 个
连接后收摊）。腿：401 双路／404／405／400 三形态／disabled 403／无端点
503／**归档红线**（仅外部端点时 503 且外部假上游零命中）／非 scope
正常路由外部／5xx 降级（审计两行 500+200）／4xx 不降级（转发 400）／
显式 model 路由＋端点 model 改写（假上游回显断言）／archive_scope
审计留痕／全端点不可用 502（连接失败 status=0 留痕）。
