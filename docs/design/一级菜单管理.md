# 一级菜单管理(界面设置)

> 状态:设计稿——未实现(2026-10-04 用户拍板,设计先行;码面无此配置,落地时随增量勾账)。定位:左侧一级菜单的显隐配置面。互引:个人任务清单与外部工具接入(UI 定位,任务清单=一级菜单)。

## 规则

- **一级菜单可配置显隐**:设置页开「界面设置·一级菜单管理」,逐项开关决定哪些一级菜单显示。
- **聊天(会话)不可关闭**——核心面,开关锁定为常开;其余(通讯录/任务清单/文件/群工具/设置等)均可关。
- 默认全开;关闭只影响入口显隐,功能与数据不动(再开启即恢复)。
- 口径统一:桌面端左栏=移动端一级 Tab,同一配置驱动;排序按用户配置(聊天恒首位)。
