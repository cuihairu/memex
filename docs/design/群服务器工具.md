## 1. 模型

- **memex agent**：轻量常驻进程，装到公用服务器（web/DB/测试机等）；向 memex server 注册（归属群/资产组），心跳上报。
- **入群即权限**（R25 同款）：进群=可见该群服务器列表+状态；退群即失。
- **三类能力**：
  1. **状态面**：CPU/内存/磁盘/负载/进程概览，agent 周期上报，列表红绿灯；
  2. **远程会话**：SSH/RDP/VNC 发起即用（web 端代理或本地协议唤起）；
  3. **动作留痕**：谁/何时/连哪台/协议/时长——进群日志（与审计面同源）。

## 2. 安全口径

- **服务器凭据只存服务端**（R24 密码箱同款加密面），客户端零凭据；会话凭证一次性短票；
- **每次接入留痕**（可选：会话录像扩展位——重度需求归 croupier，memex 先留痕不录屏）；
- 高危动作（重启服务/改配置）不进本工具面——memex 只做「看+连」，操作类走 croupier 审批流。

## 3. 与 croupier 的边界

| | memex 群服务器工具（R26） | croupier 运维会话（方案 C） |
|---|---|---|
| 场景 | 公用服务器共享使用（开发/测试机） | 生产运维（登录服务器/开发登录） |
| 权限 | 入群即得 | 票据+两人复核审批 |
| 留痕 | 接入记录 | **全程审计+录屏** |
| 凭据 | 服务端加密面 | 保险箱形态+短票注入 |

不重复建设：memex 不做录屏/审批；croupier 不做群语义。
