# 远程协助：屏幕查看＋受控方授权操作（协议面＋媒体中继）

> 状态：已实现最小闭环（2026-10-08，承 todo「三、第二期」条目四）。模型层（平台-11 Security Domain，蓝图§二十七/§五）先行已落：assist_policies／assist_sessions／assist_audits 三表、五态 requested→approved→active→closed（或 denied）、五粒度权限位 view/keyboard/mouse/clipboard/file_transfer、两条红线不设开关（consent=只有受控方本人可批/拒/随时撤；audit=全部状态迁移自动留痕）、部门放行开关默认禁沿链上溯、CLI `assist` 子命令族。本笔=协议面（FileServer HTTP）＋媒体传输（最小闭环走服务端内存中继）。

## 0. 范围拍板

- **本笔做**：会话生命周期全链 HTTP 化（发起→显式确认→启动→结束）＋屏幕帧中继（受控方推帧/发起方拉帧，服务端内存缓存最新帧）＋输入事件中继（发起方发/受控方拉走清空）＋客户端双角色窗口（发起协助/被协助）＋协议测试与对话框测试。
- **不做（留后续如实注明）**：WebRTC P2P 媒体底座（最小闭环走服务端 HTTP 中继，内网场景带宽可控；P2P 直连留 WebRTC 接入笔）、剪贴板/文件传输权限位的媒体面（模型层权限位已备，路由面只接 view/mouse/keyboard）、受控端真键盘/鼠标注入（最小闭环应用鼠标移动 QCursor::setPos 这一可移植原语；深度注入属平台层）、org-admin 全量审计面（CLI `assist audit` 已有）。

## 1. 判权与状态门（复用模型层，路由层不另造规则）

- 部门放行开关：`assist_policy_resolve` 从严双方＋默认禁（store 层 assist_request 已实现）。
- 会话当事方判权在路由层：requester/target 各自的动作面（批/拒=受控方本人；start/end=任一当事方；推帧=受控方；拉帧/发输入=发起方），az 角色矩阵不参与会话当事方面。
- 媒体门：会话须 active＋granted_mask 对应位（帧 view；mouse 类输入 mouse 位；key 输入 keyboard 位）。终态即断（受控方 end=撤权即时生效），媒体槽随即清（屏幕内容不留存）。

## 2. 媒体中继（服务端内存，不落库）

- 帧槽：`{session_id → {frame_seq, frame_b64, input_events[]}}`，单 io_context 线程不加锁；受控方推帧覆盖式（seq 自增语义由客户端维护，服务端只存最新）；**屏幕内容永不落库**——审计只记会话元数据（audit 红线的口径本来就是状态迁移，不含内容）。
- 输入事件队列：发起方 append、受控方取走即清空（FIFO、不重投）。
- 会话 closed/denied 即擦槽（受控方 end 后发起方再拉 404 语义=会话已终）。

## 3. 路由（/files/assist/*）

- POST /request {target, perms}：部门开关从严双方；自协助/幽灵/非法 perms 400；成功回 ra-<hex> 会话 id。
- POST /respond {id, approve, perms}：只受控方本人；approve 实批集 ⊆ 申请集（可缩不可扩）；deny 终态。
- POST /start {id} / POST /end {id, reason?}：当事方；受控方 active 期 end=撤权。
- GET /sessions：本人相关（发起或受控）倒序=过程持续可见＋台账面。
- GET /audit?id=：当事方读自己会话的迁移链。
- POST /frame {id, jpeg_b64, seq}（受控方）／GET /frame?id=（发起方）。
- POST /input {id, kind, x, y, key}（发起方）／GET /input?id=（受控方，取走清空）。

## 4. 客户端

- FilesClient 十方法十信号（生命周期六＋媒体四）。
- AssistDialog 双角色同窗：发起区（受控方账号＋权限勾选＋发起／会话列表〔状态〕／启动/结束／审计链）；受控区（待批请求＋实批勾选〔默认=申请集，服务端仍校验 ⊆〕／批/拒；共享中持续可见指示＋随时结束=撤权；推帧定时器抓屏 QScreen→JPEG；拉输入定时器，收到的鼠标移动应用 QCursor::setPos）。程序化入口：合成帧推送（离屏测试绕真抓屏）、权限勾选可读。
