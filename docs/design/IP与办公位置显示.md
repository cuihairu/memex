# IP 与办公位置显示

> 状态:设计稿(2026-10-04 用户拍板)。定位:会话/资料面对成员网络标识与办公位置的展示规则。

## 规则

- 对方信息展示两字段:**IP** 与 **办公位置**(办公位置来自组织架构/个人资料,无则空)。
- **设置开关两项**:
  - **IP 显示**:默认**开启**;
  - **办公位置显示**:默认**关闭**。
- **开启办公位置后,若对方没有办公位置信息,则不显示该项**——不占位、不显示空标签(无信息=无此行)。
- 开关影响的是本端显示(自己的查看界面),不改变服务端记录;IP/位置照旧只用于留痕审计面。
- 桌面端与移动端同一开关口径(设置·隐私/显示设置)。
