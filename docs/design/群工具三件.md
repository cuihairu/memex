## 1. 判权与留痕

- 全部动作判权循既有 az 规则**不自造**：群成员（`file:read` 群继承，
  入群即授权/退群即失）即可读可参与——与 R25 list/call 同款判定
  （`tool_call_allowed` 同构：`authorize({account,"file:read","group:N"})`）。
- 身份约束在服务端逻辑判（不新造 az 动词）：关票/关接龙=发起人本人或
  群主/管理员（owner||admin，同 R24-1 公告判权口径）；任务完成=负责人、
  创建者或群主/管理员。
- 幽灵口径：gid 无效/非成员一律 403（不透存在性）；poll/chain/task id
  幽灵 404（成员域内的资源号）。
- 留痕：三表台账即留痕（谁发起/谁投/谁接/谁认领/谁关/谁完成＋时刻）；
  改票覆盖、接龙更新不留修订史（轻量互动工具，审批级留痕需求不适用）。

## 2. 存储（store 三域六表）

- `group_polls`（id/topic/options_json[字符串数组]/deadline_ms[0=无，>0
  到点自动截止——惰性判定不回写 closed，见状态行实现差异]/
  closed/created_by/created_ms）＋ `group_poll_votes`（poll_id+account PK、
  choice、ts_ms；upsert=改票）。
- `group_chains`（id/title/format_hint/closed/created_by/created_ms）＋
  `group_chain_entries`（chain_id+account PK、content、ts_ms；upsert=改
  自己条目）。
- `group_tasks`（id/title/assignee[空=待认领]/due_ms/status todo|done/
  created_by/created_ms/done_by/done_ms）。

## 3. 路由（FileServer 十二条，全部群成员判权）

POST /files/group-polls（建：topic 非空、options≥2 且≤10）、
GET /files/group-polls?gid=（列表：每项带 options/每人已投/记名台账/票数
统计）、POST /files/group-polls/vote（未关、选项越界 400、改票覆盖）、
POST /files/group-polls/close（发起人或群主/管理员；已关 409）；
POST /files/group-chains、GET /files/group-chains?gid=、
POST /files/group-chains/join（未关、content 非空；一人一条 upsert）、
POST /files/group-chains/close（同 close 口径）；
POST /files/group-tasks（assignee 非空须为群成员 404 幽灵拒）、
GET /files/group-tasks?gid=、POST /files/group-tasks/claim（todo 且无人
认领，已占 409）、POST /files/group-tasks/done（负责人/创建者/群主管理
员；非 todo 409）。
