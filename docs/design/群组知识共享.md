# 群组知识共享设计：公告 / 备忘录 / 密码箱（R24 设计稿）

> 状态：设计稿（2026-10-04 用户需求）。范围：群维度的三类共享信息——公告（通知）、备忘录（共享知识）、密码箱（共享凭据）。互引：todo R24、文件存储与外网单向传输（R23）、wingman 保险箱加密方案（复用）。

## 1. 三件套与边界

| 功能 | 语义 | 可见 | 可写 | 敏感度 |
|---|---|---|---|---|
| **群公告** | 通知（置顶、全员可见、留历史） | 群成员 | 群主/管理员 | 低（明文） |
| **群备忘录** | 共享知识条目（标题+内容）：环境信息、WiFi 说明、值班表 | 群成员 | 管理员维护（可选开放示编辑+留痕） | 中（明文，**禁止放密码**） |
| **群密码箱** | 共享凭据条目（名称/账号/密码/URL/备注） | 授权成员（显式解锁） | 管理员维护 | **高（全程密文）** |

**关键分离**：备忘录与密码箱**严格不混**——备忘录明文、密码箱密文；密码一律只进密码箱，备忘录 UI 对疑似密码内容给提示。用户场景对位：后端组环境信息→备忘录；大群 WiFi 密码→密码箱（WiFi 说明文字→备忘录）。

## 2. 群密码箱（核心安全面）

- **加密方案实现参考 persona（用户指定参考件）**：persona = 对齐 1Password 的账号/保险箱体系（core/src/crypto、ssh-agent、1pux 导入）——加密面（KDF/AEAD/密钥派生）、SSH 密钥生成与导入（crypto/ssh_generate、ssh_import）、agent 化取用（ssh-agent 模式）直接参考 persona 实现，不另起加密轮子；wingman 保险箱（PBKDF2 600k→KEK→AES-256-GCM 包 DEK）作为同类先例互证。
- **查看语义**：显式解锁（输入箱密码/会话解锁），**每次查看留痕**（谁/何时/看了哪条——审计进群日志）；列表展示默认掩码（只露名称/账号）。
- **导出默认关闭**；复制密码=显式动作+留痕。
- 权限：管理员维护条目+授权名单（默认全成员可看还是仅管理员授权——**默认全成员可解锁**（共享的本意），群主可改授权名单）。

## 3. 群公告与群备忘录

- **公告**：置顶区固定入口，编辑历史留痕（谁改的/何时），@全员联动通知语义（复用三级推送：公告=重要强提醒）。
- **备忘录**：条目列表（标题+正文，支持简单分节/代码块——环境信息常贴配置），搜索内嵌；开放编辑时每条目留修订历史，可回滚。

## 4. 落地件（todo R24）
